# Acessibilidade Já! — GitHub Pages

Versão 7 — catálogo público de aplicativos gratuitos com identidade sonora acessível.

## Recursos
- Pesquisa por nome, categoria, descrição e recursos.
- Filtros por categoria e sistema operacional.
- Seção “Sobre a autora”, com a história de Alessandra Martins.
- Ficha detalhada do Estude com Alessa 2.2.0.
- Link para a página oficial de lançamentos no GitHub.
- Navegação por teclado, foco visível e anúncio dos resultados por região de status.

## Primeiro aplicativo publicado
**Estude com Alessa 2.2.0**
- Categoria: Suítes de escritório.
- Plataforma: Windows.
- Compatibilidade confirmada: Windows 11 no ambiente de teste da responsável pelo projeto.
- Windows 10: ainda não confirmado.
- Download: https://github.com/alemartinsvha-pixel/Estude-com-Alessa/releases

## Administração
O GitHub Pages publica arquivos estáticos. Não coloque senhas ou tokens em HTML, CSS ou JavaScript público. A administração segura será implementada separadamente, com autenticação real.


### Identidade sonora
A versão 6 inclui três trechos de uma faixa enviada pela responsável pelo projeto: recepção na página inicial, trecho na página de download e encerramento no fim da página inicial. Os áudios usam controles nativos, sem reprodução automática, para preservar a autonomia de pessoas que navegam com teclado e leitores de tela.

### Sobre a autora
A página inicial inclui a seção “Sobre a autora”, com a trajetória do projeto desde o Instagram, sua expansão para o YouTube e a explicação da proposta de aplicativos gratuitos. A seção está ligada à navegação principal e também pode ser acessada a partir da página de detalhes do aplicativo.
